🧩 hack-day-swap-game - Solve puzzles and fix the robot

Download Game Files Here

This project is a browser-based colour-matching puzzle game. You select clusters of matching colours to move tokens into a memory tray. The goal involves restoring a robot by filling every empty socket on the board. The game runs inside your web browser without the need for complex installations.

🕹️ About the Game

The hack-day-swap-game challenges your logic and pattern recognition skills. You see a grid filled with various coloured tokens. Your task is to group these tokens to clear the board. As you clear sections, you move pieces into the memory tray. This process powers the internal systems of the robot. You succeed when every socket on the robot contains a matched token.

💻 System Requirements

Because this game runs in your web browser, it has low system requirements. Ensure your Windows computer meets these basic criteria:

  • A modern web browser like Chrome, Firefox, or Edge.
  • An active internet connection to load the game files.
  • A mouse or trackpad for selecting tokens.
  • At least 2GB of RAM for smooth performance.

📥 How to Play

Follow these steps to access the game on your Windows machine:

  1. Visit the official project repository page to download the files.
  2. Click the green Code button and select Download ZIP.
  3. Save the folder to your Desktop or a folder of your choice.
  4. Right-click the downloaded folder and select Extract All.
  5. Open the folder after extraction finishes.
  6. Locate the file named index.html.
  7. Double-click the index.html file to open the game in your default web browser.

🎮 Gameplay Instructions

The game relies on simple mouse movements. Click on a group of connected tokens to select them. Once selected, drag or click to place them into the memory tray slots. The game tracks your progress as you fill the sockets. If you run out of moves, restart the level to try a new pattern. The difficulty increases as you progress through the robot repair stages.

⚙️ Troubleshooting

If the game does not load, verify that your browser is up to date. Occasionally, browser security settings might block local files. If the screen appears blank, try dragging the index.html file into a new tab in your browser. Ensure all files from the ZIP folder remain in the same directory so the game can find its images and scripts.
